# Aspect-Based Sentiment Analysis of MBG

## Overview
This project analyzes student opinions toward the Free Nutritious Meal Program (MBG) using aspect-based sentiment analysis.

## Objectives
- Analyze student sentiment toward the MBG program
- Identify sentiment across different aspects
- Compare machine learning models

## Aspects
- Freshness
- Nutrition
- Taste
- Portion

## Models
- Naive Bayes
- Logistic Regression
- IndoBERT

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Transformers
- Google Colab
